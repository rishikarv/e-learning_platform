# 🎓 E-Learning Portal

An interactive multi-page E-learning platform built using HTML, CSS, and JavaScript.  
This project allows users to explore courses, watch demos, enroll, and attempt assessments.

---

## 🚀 Features

- 🔐 User Authentication (Signup / Login with localStorage)
- 📚 Course Listing (Frontend, Backend, Fullstack, AI, Cloud, etc.)
- ▶️ Video Demo Integration (YouTube iframe)
- 🧠 Assessments / Practice Questions
- 📂 Assignment Submission UI (file upload)
- 📊 Course Content Sidebar (like real learning platforms)
- 🎯 Test Yourself functionality
- 🌐 Fully responsive UI

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Netlify (Deployment)  
- GitHub (Version Control)

## 🔑 Key Functionalities

### 🔹 Authentication
- Signup & Login system using localStorage
- Navbar updates dynamically (Login → Logout)

### 🔹 Courses
- Multiple course categories
- Demo videos embedded from YouTube
- Enroll button redirects to course content

### 🔹 Assessments
- Practice questions (Beginner → Advanced)
- File upload submission interface

### 🔹 Dynamic Navigation
- Buttons redirect to respective pages
- Course-based navigation system
